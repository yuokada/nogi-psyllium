# Lessons

- トグルの accessible name は状態によって切替先を示す文言へ変えず、設定名を固定し、現在状態は `aria-pressed` で伝える。
- ヘッダー内の操作要素は absolute 配置を避け、タイトル・操作・固定コーナー要素が中間幅でも重ならないレスポンシブな通常フローを設計する。
- URL と独立した UI 状態を追加した場合は、切替前後の `href`・`search`・`hash` が不変であることを明示的にテストする。
- 補助操作は画面上の関連操作群へまとめ、操作の関係と期待される並び順がレイアウトから伝わるようにする。
- アイコンだけの操作ボタンでも、固定の accessible name、状態属性、補足titleを維持して意味と状態を伝える。
